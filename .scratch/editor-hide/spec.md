# Editor Hide behavior

Editor Hide collapses the editor to its existing small floating button without
ending the process, destroying either window, or discarding the current prompt
session. Preserve the floating button's size and position. Pending enhancement
continues, and its completion must not reopen the editor.

Reopening the editor shows retained prompts, reviewed edits, and completed work.
Only Quit terminates the session. Launcher and notification-icon Hide continue
to hide both windows until restored. No frontend changes are required.

Verify through the actual WinUI Hide control with controlled HTTP responses
and isolated test credentials.
