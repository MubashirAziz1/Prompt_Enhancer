# Triage labels

When a skill names a triage role, put the corresponding value in the issue's
`Status:` line.

| Role | Status value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | `ready-for-agent` | An agent can implement the issue independently. |
| `ready-for-human` | `ready-for-human` | The issue requires a human to implement it. |
| `wontfix` | `wontfix` | The issue is closed without implementation. |
