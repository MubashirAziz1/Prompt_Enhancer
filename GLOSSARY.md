# Prompt Enhancement

Turning a user's rough idea into a clear, concise English prompt while preserving its intent.

## Language

**Rough prompt**:
The user's original English expression of an idea or request before enhancement, which may contain grammatical errors or lack structure.

**Enhanced prompt**:
A grammatically correct, structured English expression of the rough prompt that preserves the user's intent without unnecessary wording.

**Intent**:
The meaning and desired outcome expressed by the user in a rough prompt.

**Essential addition**:
A supporting detail supplied during enhancement when needed to make the user's stated goal actionable, without introducing unnecessary requirements.
